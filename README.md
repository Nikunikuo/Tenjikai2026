# AIR LOOP

展示会のための、シンプルなローカル動画の連続ループプレイヤー。

## ノート PC にクローンする

Windows、Git、Node.js 22.13 以降を用意してください。初回セットアップにはネット接続を使います。

```powershell
git clone https://github.com/Nikunikuo/Tenjikai2026.git
cd Tenjikai2026
```

非公開リポジトリなので、GitHub の `Nikunikuo` アカウントで認証してクローンしてください。GitHub CLI を使う場合は `gh auth login` のあと、`gh repo clone Nikunikuo/Tenjikai2026` でも取得できます。

1. クローンしたフォルダー内の `SETUP-AIR-LOOP.cmd` をダブルクリック。
2. セットアップ完了後、`START-AIR-LOOP.cmd` をダブルクリック。
3. ノート PC にある動画を選び、再生を開始します。

動画は Git に含めません。展示する動画は別途ノート PC にコピーしてください。準備済みのローカル版はネット接続なしで再生できます。

更新するときは `git pull` のあと、`SETUP-AIR-LOOP.cmd` をもう一度実行してください。

## すぐ使う

1. `START-AIR-LOOP.cmd` をダブルクリック。ブラウザーが開きます。
2. 「動画を選ぶ」または「フォルダーを選ぶ」で動画を追加。ドラッグ＆ドロップも使えます。
3. プレイリストの ↑ ↓ で順番を整え、再生ボタンをクリック。
4. 最後の動画が終了すると先頭から繰り返します。動画が一本だけでも繰り返します。
5. 展示中は「展示ロック」で追加・削除・順番変更を固定し、「全画面」で上映できます。

ローカル版 URL: http://127.0.0.1:4319/

`STOP-AIR-LOOP.cmd` で専用サーバーを終了します。ブラウザーを閉じてもサーバーは残るため、展示終了時に使ってください。既存の別アプリや生成ジョブには触れません。

## 空中ディスプレイで使う場合

空中ディスプレイ側の別デバイスが、操作を通常のクリック・タッチパッド入力として PC に渡す前提です。このアプリは、その通常入力で再生・停止・前後の動画選択を行います。

カメラ、手の認識、MediaPipe、認識モデルは使いません。操作ボタンを大きくし、ホバー専用のメニューを使わない構成です。全画面の操作表示は、クリックまたはポインターの移動で再表示できます。

入力のキャリブレーション、表示の反転、検出範囲などは機材側で設定してください。実機のセンサー方式やマルチタッチ対応をアプリ側では仮定しません。

## 来場者向けの作品セレクター

動画を追加すると、映像の上で次の操作ができます。全画面でも同じように使えます。

1. 映像の部分をクリックすると、番号と作品名のカードがふわっと開きます。この最初のクリックでは動画を停止・変更しません。
2. カードの帯を左右にドラッグして離すか、大きな「前の作品」「次の作品」で中央の作品を選びます。選んでいる間も上映は続きます。
3. カード、または「この作品を再生」を押すと、光の波紋とともにその作品を先頭から再生します。その後もプレイリストの順番で無限ループします。
4. 「戻る」または12秒間の無操作でカードが閉じ、上映画面に戻ります。ポインターを動かすだけではこの待機時間は延長しません。

展示ロック中も作品の選択・再生はできます。ドラッグ後のクリックは抑止するので、カードを送っただけで作品は切り替わりません。1本だけの場合は前後ボタンが無効になり、同じカードから再上映できます。キーボードでは Tab で操作先を選び、左右キーで作品を選択、Enter / Space でボタンを押し、Esc でカードを閉じられます。

作品カードの画像解析やサムネイル用の動画読み込みは行いません。端末の「視覚効果を減らす」設定にも対応しています。

## キーボード

Space: 再生 / 停止、← / →: 前 / 次、F: 全画面、M: 消音、Esc: 全画面終了。

入力欄・ボタンにフォーカスしている間はブラウザー標準のキー操作を優先します。

## 動画と会場運用

- ファイルはブラウザーの File / Object URL で参照し、サーバーへ送信しません。巨大動画を丸ごとメモリーやブラウザー保存領域に複製しません。
- リロード、タブを閉じる、再起動をした場合は動画を選び直してください。音量・ミュート・表示比率だけを保存します。
- MP4（H.264 / AAC）または WebM が扱いやすい形式です。MOV / MKV などは中のコーデックとブラウザー次第です。読み込めない動画は飛ばし、すべて失敗したら停止して案内を表示します。
- 切り替え時は次のファイルを読み込みます。フレーム単位で継ぎ目のない連結再生を保証するものではありません。
- 再生中は Screen Wake Lock を要求します。OS / ブラウザー側で拒否・解除されることがあります。会場 PC の電源設定も確認してください。
- セットアップ済みのローカル版は、オンラインサービスや CDN からの追加取得なしで再生できます。クラウド版へのアクセスにはネット接続が必要です。
- 現行 Chrome / Edge のデスクトップ版を推奨します。カメラやマイクの許可は求めません。

この PC の Node.js を利用してローカルサーバーを起動します。別 PC へ移す場合は Node.js 22.13 以降が必要です。`dist-local`、`scripts`、起動・停止 CMD をまとめてコピーすると、npm install を行わずにローカル版を起動できます。

## 開発

```powershell
npm ci
npm run dev -- --port 4318
npm run build
npm run build:local
npm test
npm run typecheck
```

Sites 版は Vinext、会場向けローカル版は同じ UI ソースを Vite で静的ビルドします。クローンした端末での利用は `build:local` と起動 CMD だけで完結し、Sites への接続や認証は不要です。

## 確認範囲

自動テストは連続巡回、一本でのループ、破損ファイルの除外、全件失敗時の終了に加え、作品カードの巡回、ドラッグとクリックの区別、縦方向・短い移動・キャンセル・追加ポインターを確認します。型検査、lint、ローカル版とWeb版のビルドも確認しています。実動画のデコード、音量、長時間上映、ブラウザー上の実操作、空中ディスプレイ機材からの入力は実機で確認してください。

主な公式資料: [Autoplay](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)、[Screen Wake Lock](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API)。
