# AIR LOOP

展示会のための、ローカル動画の連続ループ・空中操作プレイヤー。

## すぐ使う

1. `START-AIR-LOOP.cmd` をダブルクリック。ブラウザーが開きます。
2. 「動画を選ぶ」または「フォルダーを選ぶ」で動画を追加。ドラッグ＆ドロップも使えます。
3. プレイリストの ↑ ↓ で順番を整え、再生ボタンをクリック。
4. 最後の動画が終了すると先頭から繰り返します。動画が一本だけでも繰り返します。
5. 展示中は「展示ロック」で追加・削除・順番変更を固定し、「全画面」で上映できます。

ローカル版 URL: http://127.0.0.1:4319/

`STOP-AIR-LOOP.cmd` で専用サーバーを終了します。ブラウザーを閉じてもサーバーは残るため、展示終了時に使ってください。既存の別アプリや生成ジョブには触れません。

## 空中操作

「空中操作をオン」を押してカメラを許可してください。映像の録画・アップロードは行いません。カメラの小窓は鏡のように左右反転して表示します。

| 操作                                     | 動作            |
| ---------------------------------------- | --------------- |
| 手を開いて、画面で見える左へ払う         | 次の動画        |
| 手を開いて、画面で見える右へ払う         | 前の動画        |
| 親指と人差し指を合わせ、約 0.75 秒キープ | 再生 / 一時停止 |

認識した手に光るカーソルが追従します。操作後は手を一度下ろしてから次の操作を行います。二本の手が映っている間は発火を止めます。明るい場所で片手を映してください。スワイプは画面幅の約 1/4 以上、横に動かすと認識します。

初回の再生は画面の再生ボタンをクリックしてください。空中操作からの全画面化はブラウザーの制約で行いません。カメラをオフにするとストリームと認識処理を停止します。

## キーボード

Space: 再生 / 停止、← / →: 前 / 次、F: 全画面、M: 消音、Esc: 全画面終了。

入力欄・ボタンにフォーカスしている間はブラウザー標準のキー操作を優先します。

## 動画と会場運用

- ファイルはブラウザーの File / Object URL で参照し、サーバーへ送信しません。巨大動画を丸ごとメモリーやブラウザー保存領域に複製しません。
- リロード、タブを閉じる、再起動をした場合は動画を選び直してください。音量・ミュート・表示比率だけを保存します。
- MP4（H.264 / AAC）または WebM が扱いやすい形式です。MOV / MKV などは中のコーデックとブラウザー次第です。読み込めない動画は飛ばし、すべて失敗したら停止して案内を表示します。
- 切り替え時は次のファイルを読み込みます。フレーム単位で継ぎ目のない連結再生を保証するものではありません。
- 再生中は Screen Wake Lock を要求します。OS / ブラウザー側で拒否・解除されることがあります。会場 PC の電源設定も確認してください。
- ローカル版のアプリ、WASM、約 8 MB の認識モデルは同梱済みです。再生にオンラインサービスや CDN からの追加取得は不要です。クラウド版の初回アクセスにはネット接続が必要です。
- MediaPipe の入力映像は端末内で処理します。依存ライブラリーの公式 privacy notice は利用・性能メトリクスの送信についても説明しています。閉域が必要な会場ではローカル版をネットから切り離して使用してください。
- 現行 Chrome / Edge のデスクトップ版を推奨します。ブラウザーが許可を求めたときはカメラだけを許可し、マイクは使いません。

この PC の Node.js を利用してローカルサーバーを起動します。別 PC へ移す場合は Node.js 22 以降が必要です。`dist-local`、`scripts`、起動・停止 CMD をまとめてコピーすると、npm install を行わずにローカル版を起動できます。

## 開発

```powershell
npm ci
npm run dev -- --port 4318
npm run build
npm run build:local
npm test
npm run typecheck
```

Sites 版は元の Vinext 構成を使い、会場向けローカル版は同じ UI ソースを Vite で静的ビルドします。認識用アセットは `public/vendor/mediapipe` に固定し、バージョンは `@mediapipe/tasks-vision@1.0.1` です。

## 確認範囲

自動テストは連続巡回、一本でのループ、破損ファイルの除外、全件失敗時の終了、スワイプ方向、つまみ保持、連発抑止、二本手と追跡喪失を確認します。実カメラの認識率、実動画のデコード、会場照明、音量、長時間の上映は実機で確認してください。

主な公式資料: [MediaPipe Gesture Recognizer](https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer/web_js)、[MediaPipe package](https://www.npmjs.com/package/@mediapipe/tasks-vision)、[Autoplay](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)、[Screen Wake Lock](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API)。
